Fetch display events from the simulator.

With EventFilter::None this returns every event since the last clear_events, with EventFilter::CurrentScreen only those belonging to the screen currently displayed.

fn wait_event<'life0, 'life1, 'async_trait>( &'life0 self, filter: EventFilter, timeout: Duration, f: &'life1 (dyn for<'a> Fn(&'a Event) -> bool + Send + Sync), ) -> Pin<Box<dyn Future<Output = Result<Event>> + Send + 'async_trait>>
where Self: Sync + 'async_trait, 'life0: 'async_trait, 'life1: 'async_trait,

Await an event matching the provided filter, polling until timeout elapses.

EventFilter::None is the appropriate choice for most waits as the event list accumulates, so a screen that comes and goes between polls is still matched. EventFilter::CurrentScreen can miss such transient screens.

let e = handle
    .wait_event(EventFilter::None, Duration::from_secs(5), &|e| e.text == "Ready")
    .await?;
